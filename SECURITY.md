# Reporting sensitive information

Do not post credentials, customer data or exploit details in an issue or pull request. Contact a repository owner privately through a previously verified channel. If a credential has been exposed, its owner should revoke or rotate it; deleting the latest file does not remove it from Git history.

The repository validator checks a limited set of secret and private-path patterns. It cannot determine whether arbitrary prose, a customer's identity or a business detail is confidential. Human review remains necessary before publication.

These skills rely on Appmost's existing authentication, source guards and operation confirmations. They do not grant account access, retrieve signing credentials, or authorize publishing an app.
