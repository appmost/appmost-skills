# Troubleshooting

| Symptom | Inspect | Appropriate next step |
| --- | --- | --- |
| Expected tool missing | Current tools/list, host/product and client catalog freshness. | Rediscover; use a new connection/chat if the client cached an older catalog. Do not infer support from a static capability list. |
| MCP connection unavailable | App-generated setup and the intended host's availability. | Report the exact connection problem. Do not extract raw tokens or create a parallel renderer. |
| Scaffold validates but native open fails | Native package creation requirements versus the supplied working payload. | Restore the original document and use a supported native starter/template copy. Do not invent identity metadata. |
| Invalid property/template | Current schema, filtered template result and exact input contract. | Correct only the identified source; do not add aliases or new format fields. |
| Revision/context mismatch | Fresh document identity, revision and render context. | Preserve newer work and replan once from current source. |
| Asset declared but missing | Reference target versus actual bundle inventory. | Add the real resource through the supported adapter and verify it in a render. |
| Padding looks inconsistent | Measured content edges, ancestors and template intrinsic insets. | Correct the actual spacing owner; equal numeric padding alone is not evidence. |
| Render does not show new state | Saved source identity, selected dataset/language/appearance and renderer. | Render the correct source and inspect the returned metadata. |
| Tool requires access or entitlement | Existing account state and exact denial. | Let the owner use the supported sign-in/access flow. Do not bypass the gate. |
| Hosted image differs from native | Returned renderer and supported contexts. | Label evidence correctly and obtain the intended native render if available. |

Retry only after changing the input or resolving the identified cause. Stop an unchanged failing path and report the concrete blocker while finishing independent work. Never automatically repeat a build/upload/release after a lost response; use its original operation status/reconciliation contract.
